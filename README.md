# Student Internship Application Portal

## Project Overview
The Student Internship Application Portal is a Java web application developed to help students apply for internship opportunities online. The project demonstrates my understanding of Java web development and web application structure.

## Technologies Used
- Java
- Jakarta EE
- Servlets
- Maven
- Apache NetBeans
- Apache Tomcat
- HTML and CSS (where implemented)

## Main Features
- Student internship application functionality
- Java servlet-based request handling
- Maven project structure
- Web application deployment using Apache Tomcat

## Tools
- IDE: Apache NetBeans
- Server: Apache Tomcat
- Build tool: Maven

## Purpose
This project was developed as part of my Information Technology studies at Berea Technical College to improve my programming and web development skills.
